## 架构约束（持续有效）

- 模块业务逻辑留所属 `modules/`，不进 `apps/` 或其他模块
- 公共逻辑放 `packages/shared` 独立命名文件；公共 UI 放 `packages/ui` 独立组件
- `apps/` 只宿主，不放业务
- 不跨模块直接 import 私有内部实现；跨模块通信走事件总线或 `packages/shared` 契约
- 老 Lumina / 龙哥研究系统 MVP 阶段占位，不接入；Lumina 龙哥仍占位
